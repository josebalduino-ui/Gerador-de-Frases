# Gerador de Frases

Um gerador de frases aleatórias criado para fins educacionais e de entretenimento.

## 📋 Descrição

Este projeto gera frases aleatórias inspiradoras, motivacionais ou de reflexão a cada execução.

## 🚀 Funcionalidades

- Gera frases aleatórias
- Interface simples e intuitiva
- Suporte a múltiplas categorias de frases

## 💻 Tecnologias

- HTML
- CSS
- JavaScript

## 📝 Como Usar

1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Clique no botão para gerar novas frases
